# ESP32-C3 SuperMini Air Mouse Glove

Компактная Bluetooth BLE «воздушная мышь» на перчатку на базе контроллера **ESP32-C3 SuperMini** и гироскопа **MPU-6050**.

## Возможности
- Управление курсором мыши через движения руки (MPU-6050).
- Автоматическая калибровка гироскопа при старте.
- Легковесный и быстрый BLE-стек на базе **NimBLE** (совместим с Windows, macOS, Android, Linux).
- **Сцепление (Clutch / Пауза):** удержание кнопки временно замораживает курсор, позволяя вернуть руку в удобное положение. Светодиод горит постоянно.
- **Блокировка (Toggle Lock):** тройное быстрое нажатие кнопки полностью блокирует или разблокирует управление. Светодиод медленно мигает.
- **Сброс привязки Bluetooth (Unpair / NVS Erase):** удержание кнопки более 5 секунд стирает все сохраненные соединения и перезагружает плату. Светодиод быстро мерцает.

## Схема подключения (Wiring)

| Модуль | Пин модуля | ESP32-C3 SuperMini | Примечание |
|---|---|---|---|
| **MPU-6050** | VCC | 3.3V (или 5V) | При просадках лучше питать от 5V |
| | GND | GND | Общая земля |
| | SDA | **GPIO 5** | Линия данных I2C |
| | SCL | **GPIO 6** | Линия тактирования I2C |
| **Кнопка** | Вывод 1 | **GPIO 3** | Внутренняя подтяжка `INPUT_PULLUP` |
| | Вывод 2 | GND | Замыкает на землю |
| **Светодиод** | Анод (+) | **GPIO 10** | Через токоограничивающий резистор 220 Ом |
| | Катод (-) | GND | Общая земля |
| **Конденсатор** | Плюс (+) | 3.3V (или 5V) | Электролит 100-470 мкФ, параллельно керамика 100нФ |
| | Минус (-) | GND | Критичен для подавления импульсов тока BLE |

## Настройки прошивки в Arduino IDE

1. **Board:** `ESP32C3 Dev Module`
2. **USB CDC On Boot:** `Enabled`
3. **Flash Mode:** `DIO`
4. **Partition Scheme:** `Huge APP (3MB No OTA / 1MB SPIFFS)`
5. **Необходимые библиотеки:**
   - `NimBLE-Arduino` (by h2zero)
   - `ESP32-BLE-Mouse` (by T-vK)
   - `Adafruit MPU6050`
   - `Adafruit Unified Sensor`
